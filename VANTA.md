# VANTA — обновление существующего трекера

## Совместимость и хранение

Используются тот же Telegram-бот, тот же DATABASE_URL и таблица ritm_items. Обновление не удаляет и не переносит существующие записи. Разделы, заметки, дела, привычки, расписания и денежные суммы сохраняют прежний формат. Новые поля получают значения по умолчанию. Производственная база PostgreSQL не заменяется локальной SQLite.

Добавлены типы goal и profile. Единственный профиль пользователя хранится как vanta-profile. Общие приглашения и связи друзей находятся под зарезервированным владельцем __vanta_social__, который не может совпасть с проверенным числовым Telegram ID. Доступ к ним идёт только через серверные методы социальной части.

## Функции

- Сегодня: календарь недели, привычки и дела, быстрые отметки.
- Заметки: свои разделы, поиск, закрепление, превращение заметки в дело или привычку.
- Финансы: доходы/расходы, категории, месячные итоги; расчёты в целых копейках.
- Цели: произвольная единица, целевое значение, текущий прогресс, срок и направление.
- Прогресс: 7/30/90 дней, серии активности, шесть направлений.
- Персонаж: 20 XP за привычку, 30 за дело, бонусы достижений. Повторное переключение отметки не увеличивает опыт. Удаление записи убирает её вклад в статистику; это явно описано в приложении.
- Образы: Marble, Bronze (уровень 3), Obsidian (7), Spartan (12).
- Друзья: одноразовые приглашения на 7 дней, явное принятие, рейтинг среди друзей, удаление связи. Публичная проекция содержит только имя, образ и, при согласии владельца, уровень, XP и серию.
- Настройки: игровые элементы, меньше анимаций, приватность, экспорт личных записей. Вход только по проверенной подписи Telegram; самостоятельной регистрации нет.

## Развёртывание в текущий сервис Render

Обновить код в связанном репозитории. Сохранить существующие BOT_TOKEN, WEBHOOK_SECRET, DATABASE_URL и NODE_ENV=production. AUTO_CONFIGURE_BOT=1 обновит имя и меню бота на VANTA, сохранив username. Публичный адрес можно не менять. Код получает BOT_USERNAME после успешной настройки бота.

Не создавать новую базу для этого обновления. Не загружать data/, .env или node_modules в GitHub. В существующем публичном репозитории ранее присутствовали локальные SQLite-файлы; удаление их из текущего дерева Git не затрагивает PostgreSQL Render и не очищает историю Git.

Локально: Node 24, установка по pnpm-lock.yaml, npm test, npm run check, npm run dev. Переменные только для локальной проверки: DEV_AUTH=1 и NODE_ENV=development. Никогда не включать DEV_AUTH в production.

Бесплатная база, созданная 18 сентября 2026, имеет срок действия до 18 октября 2026. Постоянное хранение после этой даты требует отдельного решения до истечения срока.
